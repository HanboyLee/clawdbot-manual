## 🤖 關於 Clawdbot

Clawdbot (Moltbot) 是一個強大的 AI 自動化工具，旨在幫助你自動化日常任務，對接多種消息平台（如 Telegram、WhatsApp），並賦能你的 AI 代理「實操」能力。

### 核心功能
- **多平台對接**：支援 Telegram、WhatsApp 等通訊軟體。
- **高度可擴展**：透過技能 (Skills) 與插件 (Plugins) 系統強化 AI 能力。
- **CLI 管理**：提供直覺的命令行工具進行安裝、診斷與配置。
- **多語言支援**：手冊支援 繁體中文、简体中文 與 英文。
